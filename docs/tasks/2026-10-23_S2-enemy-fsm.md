## The decision table (this is the talking point)

```
if state is Flee or CallAllies        -> that state ends itself on a timer
else if no target                     -> Search
else if health <= fleeHealthPercent   -> Flee      (with a cooldown so it does not stutter)
else if distance <= attack.Range      -> Attack
else                                  -> Chase
```

Ranged and melee differ **only** in `EnemyStats` numbers and which `IEnemyAttack` sits on the prefab.

## Gate

- Each archetype logs all five transitions: `[EnemyBrain] RangedEnemy1: Search → Chase`, `→ Attack`,
  `→ Flee` (after damage), `→ CallAllies` (when a neighbour calls).
- A called ally turns toward the caller's target instead of wandering.
- Player takes damage from ranged shots and melee swings; enemies take damage from the player's bullets.

## Note on projectile masks

`Projectile.Launch(..., LayerMask maskOverride)` lets the **same** bullet prefab serve both sides:
the player's weapon leaves the override empty (prefab mask = everything but Player), an enemy passes
`targetMask` = Player layer only. One pool, one prefab, two rules.
