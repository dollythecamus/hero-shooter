## The decision table (this is the talking point)

```
if state is Flee or CallAllies        -> that state ends itself on a timer
else if no target                     -> Search
else if health <= fleeHealthPercent   -> Flee      (with a cooldown so it does not stutter)
else if distance <= attack.Range      -> Attack
else                                  -> Chase
```

Ranged and melee differ **only** in `EnemyStats` numbers and which `IEnemyAttack` sits on the prefab.

### Bugs this gate caught

1. **`Spyglass.Initialise` was never called** — the brain only called `Refresh`, which returned early while
   `Target == null`, so every enemy stayed in `Search` forever with `dist=Infinity`. Fixed by acquiring the
   target inside `Refresh` as well (self-healing perception), plus an explicit `Initialise` in `Awake`.
2. **Corpses kept thinking** — a killed enemy still ran the FSM and logged `Chase → Flee` at 0 hp. Fixed with
   `OnDied`: `_isDead` flag, agent disabled, `StopAllCoroutines`, ally calls ignored.
3. **`in DamageInfo` broke scripted tests** — the CodeDom compiler used by `execute_code` cannot call an
   `in`-parameter method (it demands `ref`), so `TakeDamage` was changed to pass the struct by value.

### Open balance / follow-up (not S2 bugs)

- Four enemies kill the player in ~13 s and the player has no death handling yet — belongs to HUD + game
  flow (S4), and the wave director (S6) will tune it.
- `Flee` is a 2.5 s burst with a cooldown, so a wounded enemy re-engages at 22 % health. If that reads as
  wrong on screen, it is `fleeDuration` / `_nextFleeTime` in `EnemyBrain.EndFlee`.


## Note on projectile masks

`Projectile.Launch(..., LayerMask maskOverride)` lets the **same** bullet prefab serve both sides:
the player's weapon leaves the override empty (prefab mask = everything but Player), an enemy passes
`targetMask` = Player layer only. One pool, one prefab, two rules.
